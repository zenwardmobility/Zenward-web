5. HEADER LOGO MIGRATION
------------------------
ZenwardLogo now renders /brand/zenward-logo-primary.svg (next/image,
unoptimized, so the SVG is served untouched). To keep the existing
footprint despite the artboard's clear space, the component sizes a box
to exactly the visible artwork (height prop = visible height) and
positions the full SVG inside it with negative offsets taken from the
measured bbox. The clear space overflows invisibly, nothing is clipped,
and the SVG is scaled uniformly (exact viewBox aspect).
Measured (local build): header logo box 117.8 x 32 at x=16 (390) and
x=176 (1440). Previous raster: 117 x 32 at the same positions. Header
height, nav spacing and colors are unchanged. Mobile header and mobile
navigation share the same component.
Accessibility: the header home link keeps aria-label "Zenward Mobility —
home"; the logo image inside it now has alt="" so it isn't announced
twice.
