==================================================
- Client: validateStep("passenger") requires one of the four values. The error is

6. TEMPORARY assistanceNotes COMPATIBILITY MAPPING
==================================================
- The wire key set is unchanged. There is no assistanceLevel key on the wire (tested
  in unit tests and in a live end-to-end run against a local mock).
- Flow: the form keeps assistanceLevel as structured state → buildRequestInput sends
  it as a structured input field → the Server Action validates it → buildNemrynIntakeBody
  (the server-side Nemryn mapping) encodes it immediately before building the wire
  body:

    Assistance level: Door-to-door

    Additional assistance:
    Passenger uses a walker and may need extra time at pickup.

- With no typed text, the field is just "Assistance level: Not sure", etc.
- Rules:
  - Typed text is kept verbatim.
  - Encoding is deterministic, so a retry sends the identical body.
  - Any leading encoded block is stripped first, so the prefix is never duplicated.
  - Encoding happens only in the server mapping. The form, model and Server Action
    never call it (tested).
- Length: free text is capped at ASSISTANCE_NOTES_MAX_LENGTH (2,000 minus the longest
  encoding overhead) in both the textarea maxLength and the Server Action. The encoded
  field therefore stays within 2,000 characters and nothing the visitor typed is cut
  off (tested for all four levels).
- Pre-04G3 inputs with no level map exactly as before.
- Verified end to end: the production build ran against a LOCAL HTTPS mock of the
  intake endpoint. It used a self-signed certificate, and TLS verification was relaxed
  only for that QA server process. No Nemryn or external call was made. The mock
  received:
  - assistanceNotes "Assistance level: Door-to-door\n\nAdditional assistance:\nUses a
    walker and may need extra time at pickup."
  - serviceType wheelchair_transportation (unchanged)
  - Origin header https://www.zenwardmobility.com
  - wire keys exactly from the frozen allow-list
